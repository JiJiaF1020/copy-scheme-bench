# 盈亏模型预览 v2（基于 R2 实测值，2026-10-15 蓝区）

> 性质：输入为 R2 交付 summary 表（pingpong.md §R2，**实测值**，经
> tools/breakeven_table.py 直接解析）；输出为**模型反推值**。
> 注意口径：R2 的 cpu 数据是 window=1（逐迭代延迟模式），T0_cpu 含
> ~57~120µs host 固定开销；R3 的 window=16 预期压缩 T0_cpu，ρ* 会进一步
> 左移（见末节预测）。

## 交叉点 ρ*（cpu-delta vs npu-full，R2 实测参数）

| cards | copy100 | copy300 |
|---|---|---|
| 1 | ρ*=1.20 → cpu-delta 不胜 | ρ*=0.64 |
| 2 | ρ*=1.18 → 不胜 | ρ*=0.65 |
| 4 | ρ*=0.91 | ρ*=0.18（cards4 有 R2-G4 漂移，证据弱） |
| 8 | ρ*=1.41 → 不胜 | ρ*=0.54 |

读法（模型反推值）：

- **copy300 档**：相邻步重叠 ρ > ~0.65 时 cpu-delta 已优于 npu-full——
  在 host 开销未压的 w1 形态下即成立；churn 合成演示显示稳态 ρ=0.85~0.9
  是可达区间 ⇒ 驻留+增量路线在 copy300 档**已过盈亏点**。
- **copy100 档**：ρ* > 1（cards1/2/8）⇒ npu-full 已低于 cpu 的固定开销
  本身，小 copy 数坐标 cpu-delta 结构性不胜——除非 T0_cpu 压到 npu-full
  （~48µs）以下。这定量回答了「小 top-K 时收益预期按 copy100 行估」的
  R1 预览观察。
- cards4 的 ρ*=0.18 异常低：该档 npu 有 R2-G4 环境漂移（带宽掉 20~25%），
  交叉点被漂移压低，引用时标注。

## R3 后的预测（模型反推，待 R3 实测检验）

若 w16 把 T0_cpu 从 71.8µs 压到 ~20µs（cards1 为例），其余不变：
copy300 ρ*: 0.64 → **0.37**；copy100 ρ*: 1.20 → **0.76**（从「不胜」变
「ρ>0.76 即胜」）。即：host 压减不只改善 cpu 全量形态，更直接放大
驻留+增量路线的适用域。R3 交付后回填实际 T0_cpu(w16) 验证此预测。
